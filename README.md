# TUNI Studio Recreation

A responsive, animation-rich recreation of the TUNI Studio website.

## Included pages

- `/`
- `/about`
- `/works`
- `/works/arcworks-collective`
- `/works/studio-nive`
- `/works/d-lavigne`

## Run locally

Requires Node.js 22.13 or newer.

```powershell
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Production check

```powershell
npm run build
npm run start
```

The project includes local imagery, font assets, responsive layouts, page
transitions, the opening sequence, fullscreen navigation, scroll-driven
sections, project pages, contact areas, and social sharing artwork.
